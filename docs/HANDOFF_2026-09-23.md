## 4. 함정 (오늘 실제로 밟은 것)

- **Vercel 이 커밋을 빠뜨린다.** 69549563 은 배포가 아예 안 붙었다. 빈 커밋은 「Skipped - Not affected」. **파일 한 줄이라도 실제로 바뀐 커밋**을 밀어야 빌드된다.
  확인: `curl -s https://api.github.com/repos/stockerboy/sacloud/deployments?per_page=3` → sha 와 `statuses_url`. ⚠ 익명 60회/시간 — 폴링 오래 하면 `err 0`. 그때는 DOM 을 재서(위 measure) 확인한다.
- **push 는 typecheck 초록일 때만**: `TC=$(pnpm -r --workspace-concurrency=1 typecheck 2>&1); echo "$TC" | grep -qE "error TS" && echo RED || (git push …)`.
- JSX 주석을 `{cond ? ( {/*…*/} <div> )` 처럼 **표현식 자리에 두면 TS1005**. 주석은 그 위 줄에.
- 파일은 CRLF. 파이썬으로 고칠 땐 `newline=''` 로 읽고 `\r\n→\n` 바꿔 수정 후 되돌려 쓴다 (오늘 쓴 패턴: scratchpad `*.py`).
- Bash heredoc 안에 `'` 가 든 한글 문장을 넣으면 `unexpected EOF`. 긴 패치는 `.py` 파일로 써서 `python file.py`.
- `useDrawIn`(IntersectionObserver)은 접힌 칸에서 중간에 멈춘다 → 라운드 흐름은 rAF 로 직접 긋는다(`DRAW_ON_MOUNT_MS`).
- 3rd.supply 는 헤드리스에 405. 서플라이 치수는 `docs/SUPPLY_MEASURED.md` 에 이미 잰 값을 쓴다.
