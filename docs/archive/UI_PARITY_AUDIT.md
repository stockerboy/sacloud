## 0. 관찰 조건 (읽기 전에 반드시 확인)

| 항목 | 값 |

| 관찰 도구 | `get_page_text` · `read_page`(접근성 트리) · `computer(screenshot)` |

### 지시받은 `:3100` 을 쓰지 못한 이유

- 감사 시작 시점에 `http://localhost:3100` 은 정상 응답(200)했고, **리그홈 화면은 3100 에서 스크린샷까지 캡처했다.**
- 이후 클랜랭킹으로 이동하는 도중 **3100 프로세스가 스스로 죽었다.** (`netstat` 에 3100 LISTENING 항목 소멸, 이후 모든 요청 `000`)
  나는 그 프로세스를 죽이지 않았고, 지시대로 **다시 띄우지 않았다.**
- 대체 후보 1 — 운영 URL `https://sacloud-web-softgw01-8957s-projects.vercel.app` : HTTP 200 이지만
  **모든 데이터 화면이 스켈레톤에서 멈춘다**(백엔드/DB 미연결). 비교 불가.
- 대체 후보 2 — **`http://localhost:3000`** : 이미 떠 있던 dev 서버. 죽이거나 새로 띄우지 않았다.
  3000 의 리그홈 렌더 결과가 3100 에서 찍은 스크린샷과 **픽셀 수준으로 동일**함을 확인하고 이것으로 계속했다.
  (dev 서버라 첫 진입 시 라우트 컴파일에 10~60초가 걸린다. 스켈레톤이 오래 보이는 것은 **차이가 아니다.**)

### 관찰 제약 — 색·간격·굵기는 두 화면만 검증됨

감사 중반부터 Chrome 확장의 **스크린샷 기능이 지속적으로 실패**했다
(`Failed to deserialize params.clip.scale`, `Failed to get viewport information`, 접근성 트리 `Viewport: 0x0`).
브라우저 창이 백그라운드/0 크기로 잡히는 문제로 보이며, `resize_window` 로도 복구되지 않았다.

그 결과:

- **색 · 간격 · 정렬 · 굵기까지 비교한 화면**: 리그홈, 클랜랭킹 (스크린샷 확보)
- **텍스트·구조·순서·포맷·링크만 비교한 화면**: 개인랭킹, 클랜 상세, 선수 상세, 리그 목록, 게시판
  → 이 화면들의 **색/간격 차이는 이 문서에서 판정하지 않았다.** 재검수가 필요하다.

### 판정에서 제외한 것

- **광고** (`CLAUDE.md` 4장). 원본 리그홈·게시판·선수 상세의 AdSense 배너/인피드/`Advertisement` 블록은 전부 "차이 아님".
- **SACLOUD 브랜드** — 로고, 서비스명, 브랜드 색, 푸터 문구(`© 2026 SACLOUD`, `sacloud@local.invalid`), 안내 문구 재작성.
- **데이터 양** — 우리 DB 경기 수가 적어 목록이 짧은 것, 클랜 수(44 vs 48), 래더 값, 닉네임 목록.

## 14-7. 남은 일 — 이 재감사가 대신할 수 없는 것

**렌더 검수 1회가 필요하다.** 위 `C` 37건은 전부 코드 근거이고 화면에서 확인한 것이 아니다.
`CLAUDE.md` 3장 8번의 6개 항목으로 아래 화면을 실제 브라우저에서 한 번씩 본다.

```
리그홈 · 클랜랭킹 · 개인랭킹 · 클랜 기록실 · 선수 기록실 ·
경기 상세(펼침) · 리그 목록 · 게시판(자유 + Hot) · 404
```

특히 볼 것 — **코드만으로는 절대 안 보이는 것들**:

1. **경기 상세 펼침이 실제로 펼쳐지는가.** 원 감사에서 5회 시도해 실패했고 아직 아무도 못 봤다
2. **글자가 바닥색(`#060505`)에 묻히지 않는가.** D-204 가 고친 결함이 정확히 이것이었다
   (`--color-ink` 로 그리던 글자가 바닥과 같은 색이었다). 같은 함정이 다른 화면에 남아 있을 수 있다
3. **`a { color: inherit }` 함정.** `<a>` 에 직접 준 색 유틸리티가 눌린다 — 활성 탭이 실제로 빨갛게 뜨는가
4. **진홍이 넓은 면에 칠해지지 않았는가.** 승률 65%↑ 노랑 · 1위 진홍이 의도대로 나오는가
5. **가로 스크롤이 `body` 에 생기지 않는가** (부록 A 모바일 계획과 함께 본다)
