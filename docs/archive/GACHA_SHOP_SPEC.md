해석이 갈리면 **아래가 기준이다.** 오타·띄어쓰기 포함해 손대지 않았다.

> 알때기 말고 가챠샵 컨셉으로 가자 그 가챠상자 안에 원모양 캡슐처럼 클랜마크가 담겨있고
> 약간 그 불투명한 공모양 그걸로. 포장하고(클랜마크 살짝 보여야함 불투명하게) 그리고
> 케이스위에 클랜이름 써놓고 보이게 해줘 IPL DPL만 넣고 영상 등록 클랜은 필요없어 빼
> 총 몇개지 그럼 아무튼 다 때려넣고 모든 가챠가 쌓여있는것처럼 연출해 그리고 내 클랜 뽑기
> 이런식으로 만들어놓고 클랜명 검색하고(클랜명에 특문과 어려운 영어가 많으니 veritas 클랜을
> 가정하면 유저가 베리타스 이런식으로 검색하면 나오게 해줘(그리고 클랜명을 한글로 치셔도
> 나옵니다 exOnePoinT >원포 로쳐도 나옴) 문구 유저가 볼 수 있게 해주고 클면 넣고 돌리면
> 그게 딱 나오면 유저가 그걸 열 수 있게해줘 ( 클랜원이어야하고 그런거 상관없음) 열면 딱
> 케이스가 열리면서 SA CLOUD 라는 진열대에 예쁘게 올리고 문구를 띄워줘 이제 볼 수 있는것들을
> 다 알려줘 등록돼서 볼 수 있는것들을 다 알려주면 돼

이어서 (같은 날):

> 진열대는 클랜이 여러개 쌓이면 그 한줄로 지나가게 보여줘 회전초밥집처럼 계속 도는거야
> (한줄이 꽉차면 돌리면서 클랜을 전부 보여줘)

### 원문에 들어 있는 지시 여덟

1. **캡슐** — 동그란 불투명 공. 안에 클랜마크가 **흐릿하게** 비친다
2. **케이스 위에 클랜 이름** — 캡슐에 붙은 띠에 쓴다
3. **DPL · IPL 만** — 열산 · 대룰은 뺀다
4. **다 쌓아 놓는다** — 격자로 줄 세우지 않고 **더미**로 보인다
5. **내 클랜 뽑기** — 이름으로 찾아 **그것이 나온다**. 진짜 무작위가 아니다
6. **한글로 쳐도 찾아진다** — `베리타스` → `veritas` · `원포` → `exOnePoinT`. **안내 문구를 띄운다**
7. **아무나 열 수 있다** — 클랜원 확인 안 한다
8. **진열대는 돈다** — 회전초밥처럼 한 줄로 계속 지나간다

## 3. 무엇이 바뀌고 무엇이 안 바뀌나

| | 알 (옛 연출) | 가챠 (새 연출) |
|---|---|---|
| 잠긴 것 | 알 | **캡슐(불투명 공)** |
| 여는 행위 | 깬다 | **뽑아서 연다** |
| 여는 조건 | 인증 · 클랜마스터 · 관리자 | **그대로** (D-222) |
| 서버 기록 | `EggBreak` 표 | **그대로. 표 이름을 바꾸지 않는다** |
| API | `/api/eggs/broken` · `/api/admin/eggs` | **그대로** |
| 무엇을 가리나 | 승률 · 승패 · 육각형 · 킬뎃 | **그대로** |
| 홈 화면 | 알 모음집 | **가챠 더미 + 뽑기 + 도는 진열대** |

> **표 이름과 경로를 바꾸지 않는 이유** — 바꾸면 마이그레이션 · API · 관리자 화면 · 캐시 키가
> 전부 따라 움직인다. **비유가 바뀌었다고 배관을 다시 깔지 않는다.**
> 코드 안의 `egg` 는 «가리는 장치» 를 가리키는 이름으로 계속 쓰고, **화면 글자만** 가챠로 쓴다.
> 옛 알 컴포넌트도 지우지 않는다 (`CLAUDE.md` 10-4).

## 4. 흐름

```
① 더미        105개 캡슐이 쌓여 있다. 이름이 보인다. 마크는 흐릿하다
② 찾기        「내 클랜 뽑기」 — 이름을 친다. 한글로 쳐도 된다
③ 뽑기        고른 캡슐이 더미에서 나온다. **무작위가 아니다 — 고른 것이 나온다**
④ 열기        케이스가 열린다. 마크가 또렷해진다
⑤ 진열        SACLOUD 진열대에 올라간다. 여러 개면 **회전초밥처럼 한 줄로 돈다**
⑥ 문구        「이제 볼 수 있는 것」을 알려 준다
```

### 4-1. ③ 이 무작위가 아닌 이유

사용자가 *"클면 넣고 돌리면 그게 딱 나오면"* 이라고 했다. **돌리는 연출은 하되 결과는 정해져 있다.**
가챠의 재미는 «무엇이 나올까» 가 아니라 **«내 클랜을 꺼낸다»** 에 있다.
진짜 무작위로 만들면 남의 클랜이 나오고, 그건 사용자가 시킨 것이 아니다.

### 4-2. ⑤ 진열대 (2026-09-01 추가)

- **한 줄로 끊김 없이 돈다.** 목록을 두 벌 이어 붙이고 `translateX(-50%)` 까지 움직인 뒤 되돌린다
- **한 줄이 안 차면 돌리지 않는다.** 가운데 정렬로 세워 둔다
- 속도는 **개수와 무관하게 일정한 픽셀 속도**다. 많아진다고 빨라지면 안 된다
- **손을 얹으면 멈춘다.** 읽을 시간을 줘야 한다
- `prefers-reduced-motion` 이면 **안 돈다.** 대신 손으로 미는 가로 스크롤이 된다

## 5. ⑥ 「이제 볼 수 있는 것」 문구

`EGG_SYSTEM_SPEC.md` 3장의 잠금 표를 **그대로** 사람 말로 옮긴 것이다. 새로 만든 규칙이 아니다.

```
열렸습니다. 이제 <클랜명> 의 기록을 볼 수 있습니다.

  승률          몇 %인지
  전적          N승 N패
  클랜 육각형    스나싸움 · 소수싸움 · 세이브 · 게임템포 · B어택성공 · A어택성공
  경기별 육각형  경기 상세에서 양 클랜을 겹쳐 봅니다
  킬뎃          DPL 만 해당합니다 (IPL 은 원래 없습니다)
  클랜원 목록    접속중 / 미접속

  판수와 경기 상세기록은 처음부터 보였습니다 — 그건 가린 적이 없습니다.
```

- **마지막 줄을 빼지 마라.** 안 가렸던 것을 «이제 보인다» 고 말하면 거짓이 된다
- 실제로 값이 없는 항목(배틀로그가 없어 육각형이 `측정중`)은 **그렇다고 적는다.**
  «볼 수 있다» 고 해 놓고 빈 화면이 나오면 그게 더 나쁘다

## 6. 한글 검색 (지시 6)

```
veritas      ← 베리타스 · 베리 · veri · VERITAS
exOnePoinT   ← 원포 · 원포인트 · 엑스원
des`per@do.  ← desperado · 데스퍼라도   (특수문자 무시)
베이직        ← ㅂㅇㅈ                    (초성)
```

- 로마자를 **한글 읽기로 바꿔** 두고, 검색어가 그 읽기의 **부분**이면 걸린다
- 읽는 법이 갈리면(`c` → `ㅋ`/`ㅅ`) **여러 개를 만들어** 하나라도 걸리면 통과
- `ceIestial` · `FlexibIe` 처럼 **대문자 I 가 소문자 l 인 척**하는 이름이 실제로 있다.
  눈으로 보고 치는 글자는 `l` 이므로 둘을 같게 본다
- **안내 문구를 화면에 띄운다** (사용자 지시): «클랜명을 한글로 치셔도 나옵니다»

구현은 `packages/contract/src/clanSearch.ts` 다. **순수 함수이고 DB 를 모른다.**

## 7. `[미확인]` — 우리가 정하지 않은 것

| 표기 | 무엇 |
|---|---|
| `가-1` | 이미 열린 클랜을 **다시 뽑으면** 어떻게 되는가 (그냥 진열대로 보내는가) |
| `가-2` | 진열대에 **누가** 올라가는가 — 내가 연 것만인가, 전체가 연 것 전부인가 |
| `가-3` | 캡슐 더미의 **순서** — 래더순인가 이름순인가 무작위(고정 시드)인가 |
| `가-4` | 열산을 **영영** 빼는가, 지금만 빼는가 (356곳이라 더미가 4배가 된다) |
| `가-5` | 「뽑기」 연출의 길이 — 몇 초가 적당한가 |

> `가-2` 는 특히 중요하다. **«전체가 연 것»** 이면 진열대가 계속 길어지고 회전이 의미를 갖는다.
> **«내가 연 것»** 이면 대부분 한두 개라 안 돈다. **사용자 원문의 «클랜이 여러개 쌓이면» 은
> 전자로 읽힌다** — 그래서 일단 **전체가 연 것**으로 만든다. 아니면 바꾼다.
