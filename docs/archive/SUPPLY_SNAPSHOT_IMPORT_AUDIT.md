## 0. 방법 — 공식을 복제하지 않았다

래더 예측은 **실제 `runRate` 코드**로 돌렸다. 별도 시뮬레이터를 만들면 언젠가 갈라지고,
갈라진 예측은 예측이 아니다. `runRate` 에 `extraMatches` 주입 지점만 더했고,
`ctx.dryRun` 이 아니면 주입을 **거부**한다.

**하네스를 먼저 검증했다.** 아무것도 주입하지 않고 dry-run 을 돌려 현재 DB 래더와 대조했다.

## 13. 가오픈 전에 넣을 것인가 — **권고: 아니오 (가오픈 후)**

넣으면 좋아지는 것

- 래더 경기 98 → 604 로 6배. 구성 보정이 처음으로 동작한다
- 무기별 집계에 잡히는 선수가 286명에서 **1,300~1,800명 규모**로 늘어 화면이 채워진다

그럼에도 **가오픈 전을 권하지 않는 이유**

1. **4장의 팀 판정 문제가 먼저다.** 현재 래더 98경기 중 24건이 의심스럽고,
   같은 성격의 문제가 투영에서 86건 나온다. 이걸 정리하지 않고 590건을 얹으면
   문제가 6배로 커진 상태에서 원인을 찾게 된다.
2. **점수 체감이 달라지지 않는다.** 4000+ 는 넣어도 0명이고 최고점은 3,228 이다.
   판수 중앙값이 2라 confidence 가 15% 수준이다 — 가오픈 화면이 크게 좋아지지 않는다.
3. **선수가 260 → 1,475 로 늘고 새 Player 664명이 생긴다.** 되돌릴 수는 있지만
   가오픈 직전에 감수할 변화 폭이 아니다.
4. 반대로 **미루는 비용은 낮다.** 스냅샷 파일은 그대로 있고, 적재는 idempotent 하게
   설계할 수 있다. 언제 넣어도 결과는 같다.

> 순서 권고: **가오픈 → 팀 판정 정리 → 590건 적재 → replay → 무기 재집계.**

## 14. 되돌리기 계획 (실제 적재 승인 시)

적재·replay·무기 재집계를 **각각 따로** 되돌릴 수 있어야 한다.

### 적재 전에 반드시

```bash
pnpm --filter @sacloud/worker nexon db-snapshot          # 51모델 행 수 · 기간 · 무결성
pnpm --filter @sacloud/worker nexon rating-backup --league supply   # 래더 스냅샷(체크섬)
```

무기 집계는 `MatchPlayerStat` 에서 **언제든 다시 만들 수 있으므로**
별도 백업이 필요 없다 (`weapon-rebuild` 는 결정적이다).

### 되돌리는 방법

| 대상 | 방법 |
|---|---|
| 적재된 경기 | `Match.origin = '3rd.supply-import'` 로 표시해 두고 그 값으로 삭제 |
| 새로 만든 Player | `origin = '3rd.supply'` 이면서 `MatchPlayerStat` 이 0건인 것만 삭제 |
| 래더 | `nexon rating-restore --league supply --file <백업>` |
| 무기 집계 | `nexon weapon-rebuild --league supply --confirm` 재실행 |

**기존 136경기는 건드리지 않는다.** 적재는 새 `matchId` 에만 쓴다.

## 15. 승인 후 실행할 명령 (아직 실행 금지)

적재 도구(`snapshot-import`)는 **아직 만들지 않았다.** 이번 작업은 감사까지다.
만들 때 반드시 지킬 것 —

- **기본이 dry-run.** 실제 쓰기는 `--confirm` 이 있어야만
- 이미 있는 `matchId` 는 건너뛴다 (덮어쓰기 금지가 기본)
- 참가자 10명 초과면 FAIL · 중복 참가자면 FAIL
- 충돌은 건너뛰고 사유를 남긴다
- K/D 가 없으면 `null` 그대로. **0으로 채우지 않는다**
- 출처(`source` / `sourceMatchId` / `fetched_at`)를 보존한다
- idempotent — 두 번 돌려도 같은 결과

```bash
# 0) 감사 재확인 (지금 바로 돌려도 안전하다)
pnpm --filter @sacloud/worker nexon snapshot-audit --league supply

# 1) 백업
pnpm --filter @sacloud/worker nexon db-snapshot
pnpm --filter @sacloud/worker nexon rating-backup --league supply

# 2) 적재 (도구 구현 후)
pnpm --filter @sacloud/worker nexon snapshot-import --league supply            # 미리보기
pnpm --filter @sacloud/worker nexon snapshot-import --league supply --confirm

# 3) 래더 재계산
pnpm --filter @sacloud/worker nexon rate --league supply

# 4) 무기 재집계
pnpm --filter @sacloud/worker nexon weapon-rebuild --league supply --confirm

# 5) 검증
pnpm nexon:check
pnpm --filter @sacloud/worker nexon db-snapshot
```
