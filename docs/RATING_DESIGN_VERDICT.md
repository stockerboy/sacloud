## 1. 최종 등급 — **PASS WITH TUNING (74 / 100)**

| 항목 | 배점 | 점수 | 근거 |
|---|---|---|---|
| 실제 실력 반영 | 25 | **19** | 스피어만 0.904 (10시드 평균 0.90). 다만 실제실력 top30 중 표시 top30 안에 든 것은 16명, top50 안이 26명 |
| 판수 박치기 방지 | 15 | **14** | archetype A(1000판·저실력) 220명 중 96위. 신뢰도가 150판에서 멈춰 더 쌓아도 안 오른다 |
| 양학 방지 | 15 | **8** | 개인은 Elo가 막는다(4000 vs 3000 승리 +2.7점). **클랜은 못 막는다** — 구성 보너스가 상대 강도와 무관하게 정액이다 |
| 신규 고수 공정성 | 10 | **8** | P(22판·실력3550) 42위, E(46판) 51위로 눌린다. 의도대로지만 억제가 다소 세다 |

| 열빡형 과대평가 방지 | 5 | **5** | 탐지 알고리즘 **없이** 억제된다 — 고정팀 순증 240 vs 재편형 30 |

**시뮬레이션으로 확인됐다.** 그러나 클랜래더 쪽에 구조적 문제가 셋 있고, 그대로 내보내면
시즌이 갈수록 왜곡이 커진다.

## 2. 개인 1위가 왜 1위인가

```
1위  player-3     180판  95.6%  KD 84.3  MVP율 51%  평균상대 2885  업셋 0   표시 3387  (실제실력 3578)
2위  archetype-L  250판  74.0%  KD 64.6  MVP율  8%  평균상대 3072  업셋 1   표시 3382  (실제실력 3344)
```

**1위는 이 모집단에서 실제로 가장 잘하는 선수다** (hidden skill 3578, 220명 중 1위).
공식은 그 값을 보지 못하는데도 1위로 올렸다 — 이건 시스템이 제대로 작동한 사례다.

다만 **평균 상대가 2885로 낮다.** 일정이 쉬웠는데도 1위인 이유는
승률 95.6%가 압도적이라 Elo가 그 격차를 결국 반영했기 때문이다.
2위와의 차이는 **5점**(3387 vs 3382)에 불과하다 — 쉬운 일정이 사실상 이득을 주지 못했다.

2위는 정반대 경로다. 승률은 21%p 낮지만 **평균 상대가 187점 높고 강자전이 28판**(1위는 2판)이다.
"쉬운 일정 + 압도적 승률"과 "어려운 일정 + 견실한 승률"이 5점 차로 붙는 것은 납득 가능하다.

## 3. 클랜 1위가 왜 1위인가

```
1위  clan-7   91전  94.5%  평균 본클랜원 2.43  보너스누적 +372  base누적 +251  rating 3623  (실제전력 2위)
```

실제 전력 **2위** 클랜이 래더 1위다. 승률 94.5%로 Elo 기본점수(+251)를 벌었고,
구성 보너스(+372)가 얹혔다. 보너스 기여가 **60%** 로 절반을 넘는다.

즉 1위 자체는 타당하지만 **순위를 만든 주된 힘이 실력이 아니라 보너스**다.
이것이 아래 문제 1과 직결된다.

## 4. 가장 심각한 문제 3개

### 문제 1 — 구성 보너스가 Elo를 이긴다 (**가장 심각**)

```
clan-65   438전  70.8%  평균 본클랜원 3.33
          base 누적  -1,762      ← Elo 기준으로는 **내려가야 할 클랜**
          보너스 누적 +2,178
          최종 rating 3,416  →  6위
```

Elo는 이 클랜이 상대 대비 기대에 못 미쳤다고 말하는데(누적 -1,762),
구성 보너스가 그것을 통째로 덮고 6위로 올려놨다.

상위 10개 클랜 중 **평균 2.4개**가 이렇게 base 누적이 음수다.
top10의 보너스 기여도는 평균 **51%** — 순위의 절반이 실력이 아니다.

원인은 두 가지가 겹친 것이다.
- 보너스가 **상대 강도와 무관하게 정액**이다 (약팀을 이겨도 +12)
- 보너스가 **패자에게서 빠지지 않는다** → 이기기만 하면 무조건 순증

그래서 **판수를 많이 치는 클랜이 유리하다** — 사용자 질문 4번의 답은 **그렇다**이다.

### 문제 2 — 목표 rating 에 아무도 도달하지 못한다

목표 체감은 `4000+ 랭커 · "41층"(4100) · 시즌 최상위 4300±200` 이었다.

```
실측 1위       3,387
상위 1%        3,380
50위           3,137
중앙값         2,991

K=40 → 1위 3,384      K=50 → 3,388
K=60 → 3,387          K=70 → 3,398
```

**K를 40에서 70까지 바꿔도 1위가 14점밖에 안 움직인다.** K로는 못 푼다.

이유는 구조적이다. 전원이 3000에서 시작하고 상대도 3000 근처인 폐쇄 풀에서
Elo는 "그 사람의 실력이 풀 평균보다 얼마나 위인가"에 수렴한다.
4300에 도달하려면 풀 평균보다 1300점 위여야 하는데, 그건 승률 99.5%에 해당한다.

**4000+ 를 실제 체감으로 만들려면 공식이 아니라 스케일을 손봐야 한다.**
예: Elo 분모 400 → 200으로 줄이거나(격차 2배), 표시 배율을 따로 두거나,
baseline 을 3000이 아닌 다른 값으로 두고 스프레드를 재설계.
**이건 결정 사항이라 임의로 바꾸지 않았다.**

### 문제 3 — inflation 에 상한이 없다

```
시즌 1회       클랜 rating 순증  +12,606점 (경기당 +2.19)
평균 클랜 rating  3,000 → 3,128
멸망전 50연전만으로도 두 클랜이 각각 +300
```

보너스가 positive-sum이라 **경기를 하면 할수록 리그 전체 점수가 늘어난다.**
시즌마다 초기화하지 않으면 몇 시즌 뒤에는 절대값이 의미를 잃는다.

특히 **실력이 대등한 두 클랜이 50연전만 해도 둘 다 +300**이 된다.
"같은 상대 반복"을 벌주면 안 된다는 원칙은 지켜야 하지만,
그 원칙이 **점수 생성을 무제한 허용해야 한다는 뜻은 아니다.**

## 5. 그 밖에 확인된 것

### 잘 작동하는 것

- **멸망전은 보존된다.** 반복 감쇠 없이도 Elo가 정상 수렴한다
  (M3 클5 vs 클5 50연전 → 26승 24패, 후반 평균 |delta| 38.6)
- **열빡은 탐지 없이 억제된다.** 같은 10명·같은 20경기로 비교했을 때
  고정팀 순증 240 vs 팀재편형 30. 팀을 섞으면 본클랜원이 5.0 → 2.0으로 떨어지고
  대표 클랜을 정할 수 없는 경기가 늘어 자연히 보너스가 줄어든다.
  **사용자의 핵심 가설이 수치로 확인됐다**
- **클1이 부당하게 막히지 않는다.** 클랜 2위(clan-89)는 평균 본클랜원 1.00,
  보너스 0으로 순수 Elo만으로 올라왔다. 사용자 질문 2번의 답은 **아니다**
- **판수 박치기가 막힌다.** 1000판 저실력 A는 96위
- **개인 양학은 Elo가 막는다.** 4000이 3000을 이기면 +2.7점

### 포지션 편향 — 퍼포먼스 비중에 정비례한다

```
비중 ±0%  → 스나-서포트 격차  0.2점   스나 top20 비중 25%
    ±5%  →                  5.5점                   30%
    ±10% →                 10.6점                   30%
    ±15% →                 15.7점                   30%
실력 상관은 0.902 ~ 0.904 로 **전 구간 사실상 동일**
```

경기 생성기가 스나이퍼에게 일부러 킬 ×1.22, MVP ×1.35를 줬다.
그 상태에서 퍼포먼스 비중을 올릴수록 편향이 **선형으로 커지는데 정확도는 안 오른다.**
즉 퍼포먼스 가중치는 **정확도를 사지 못하고 편향만 산다.**

### 신뢰도 방식

```
A · 표시값만 (display)   상관 0.904   신규(60판 미만) 최고 16위   top50 내 신규 7명
B · delta 에 곱함        상관 0.919   신규 최고 9위               top50 내 신규 9명
```

B가 정확도는 조금 낫지만 신규를 덜 억제한다.
A는 "내부 점수는 이만큼이고 신뢰도만큼만 보여 준다"고 **설명하기 쉽고**,
150판 전 억제라는 목적에 더 맞는다.

## 6. 대안 비교 (같은 시드 · 같은 모집단)

확정안을 먼저 그대로 돌린 뒤, **값은 그대로 두고 지급 방식만** 바꿔 재실행했다.

| 모드 | 실제전력 상관 | rating 순증 | top10 보너스 기여 | top10 중 base 음수 |
|---|---|---|---|---|
| **current (확정안)** | 0.858 | **10,744** | **51%** | **2.4개** |
| zero-sum (패자가 부담) | 0.855 | **0** | 49% | 2.8개 |
| **opponent-scaled** | **0.859** | 7,442 | **29%** | **0.2개** |
| separate-track (래더 제외) | 0.852 | 0 | 0% | 0.0개 |

`opponent-scaled` = 보너스 × 2 × (1 − 기대승률). 약팀을 이기면 보너스가 거의 없고,
대등하거나 강한 상대를 이기면 정액 그대로(+12) 받는다.

**+0/3/6/9/12 값은 그대로 두면서** 문제 1을 거의 제거한다
(base 음수 2.4개 → 0.2개, 보너스 기여 51% → 29%). 상관도 유지된다.

`zero-sum` 은 inflation 을 완전히 없애지만(순증 0) base 음수는 오히려 늘었다 —
총량만 잡고 "판수로 올라가는" 문제는 못 잡는다.

**둘을 같이 쓰면**(opponent-scaled + zero-sum) 문제 1과 3을 동시에 잡을 수 있다.
다만 zero-sum 은 "패자에게서 뺀다"는 점에서 사용자의 "패배 추가 패널티 없음" 원칙과
해석이 갈릴 수 있어 **사람의 결정이 필요하다.**

## 7. "정말 잘하는 사람이 순위권에 드는가" — 정직한 답

사용자 정의(150~500판 · 승률 55~65% · KD 상위권 · 강한 상대)에 맞는 선수는 4명이었고,
**top30 안에 0명**이었다 (37 · 61 · 68 · 83위).

그런데 이것을 바로 FAIL로 볼 수는 없다. 그 4명의 실제 실력은 3173~3301이고,
표시 top30의 평균 실제 실력은 3302, 최저가 3117이다.
즉 **그들은 top30 경계선에 있는 사람들이지 명백한 상위권이 아니다.**

문제는 다른 데 있다 — **이 시뮬레이션에는 매치메이킹이 없다.**
상위 10명의 승률이 96 · 87 · 84 · 80 · 75 · 74 · 73 · 71 · 67 · 67% 다.
실제 클랜전은 비슷한 상대끼리 붙으므로 승률이 50~65%로 압축된다.
**"승률 55~65%가 상위권"이라는 사용자의 감각은 매치메이킹이 있는 리그의 감각이고,
이 모델에는 그것이 없다.**

그래서 이 항목은 **판정 보류**로 둔다. 다시 검증하려면
상대 선택을 rating 근접 기준으로 바꾼 매치메이킹 모드를 추가해야 한다.
지금 결과로 "잘하는 사람이 안 올라간다"고 결론 내리는 것은 근거를 넘는 주장이다.

실제실력 상위 30명의 표시 순위는 `1,2,3,4,5,6,8,10,12,13,14,16,18,22,29,30,32,...,67` 이다 —
**16명이 top30, 26명이 top50.** 재현이 안 되는 수준은 아니지만 완벽하지도 않다.

## 8. 권고

| 항목 | 권고 | 이유 |
|---|---|---|
| **+0/3/6/9/12 유지** | **값은 유지 · 지급 방식은 `opponent-scaled` 로 변경 권고** | 값을 바꾸지 않고 문제 1을 거의 제거한다 (base 음수 2.4 → 0.2) |
| **K** | **50** | 상관은 K=40이 최고(0.916)지만 차이가 미미하고, 낮을수록 신규 적응이 느리다. 50이 절충 |
| **신뢰도 방식** | **A (표시값만)** | 정확도는 B가 약간 높지만 설명이 쉽고 150판 전 억제 목적에 맞는다 |
| **개인 퍼포먼스 비중** | **±5%** | ±10%·±15%는 정확도를 못 올리면서 포지션 편향만 선형으로 키운다. 0%도 방어 가능 |
| **inflation** | **시즌 종료 시 재센터링 필요** | positive-sum에 상한이 없다. 시즌마다 baseline 으로 되돌리거나 zero-sum 병행 |
| **목표 rating(4000+)** | **별도 결정 필요** | K로는 안 된다. Elo 분모·표시 배율·baseline 중 하나를 바꿔야 한다 |

## 9. 아직 검증하지 못한 것 (정직하게)

- **매치메이킹이 없다.** 실제 리그의 승률 분포와 다르다 (7장)
- **시즌 간 이월**을 보지 않았다. 여러 시즌 누적 inflation 은 미검증
- **이적 악용**(match-time affiliation 조작)은 모델에 넣지 않았다
- 개인 rating 과 클랜 rating 사이의 **상호작용**(용병 수요 등)은 미검증
- 100 Monte Carlo 가 아니라 **10 시드**로 돌렸다 (시드당 약 10초)

# 부록 A — 후보 1안 검증 (D-140)

사용자가 위 결과를 보고 정한 **운영 후보 1안**을 같은 시드·같은 모집단으로 검증했다.

## A-1. 설계

```
개인   내부 Skill Elo · K 50
       퍼포먼스 ±5%
       신뢰도는 **표시값에만** (내부는 계속 정상 계산)
       표시 배율로 3000~4300대 점수판 생성

클랜   내부 Clan Elo · K 50 · **순수 제로섬**
       모든 정상 5v5 반영 (클1용4도 정상 점수 · official 게이트 없음)
       구성은 누적 보너스가 아니라 **최근 20경기 평균 본클랜원**으로 계산한
       **상한 100점**의 보정
       최종 클랜 점수 = Elo + 구성 보정(0~100)

공통   반복 상대 감쇠 없음 (탐지만, 자동 감점 없음)
```

# 부록 B — 후보 2안 검증 (D-141)

사용자가 "승률·상대강도 >>> KD/MVP" 를 최우선 원칙으로 못 박고,

## B-0. 가장 중요한 것 — **내 판정 기준이 틀렸었다**

처음 돌렸을 때 이렇게 판정했다.

```
KD 순위상관 0.770 · 승률 0.914 → 차이 0.145 → "KD 영향이 너무 크다" FAIL
```

그런데 퍼포먼스 비중을 **0% 로 놓고** 다시 재 보니 **KD 상관이 0.761** 이었다.
KD 가 점수에 **아무 영향도 줄 수 없는 상태**에서 나온 값이다.

이유는 당연하다 — **잘하는 선수는 원래 KD 가 높다.**
`상관은 인과가 아니다.` raw 상관으로 판정하면 어떤 설계를 넣어도 영원히 FAIL 이 나온다.

그래서 판정을 **0% 대조군과의 차이**(인과 몫)로 바꿨다.

```
KD 상관 0.813 · 0% 기준선 0.809  →  인과 몫 **+0.004**
```

**퍼포먼스가 KD 를 통해 순위에 기여하는 몫은 사실상 0이다.**

## B-1. 무엇이 순위를 만드는가

| 설명변수 | 순위와의 상관 | 인과 몫 |
|---|---|---|
| **일정 감안 승리의 질** (기대 대비 초과 승리) | **0.974** | — |
| 승률 | 0.919 | — |
| KD | 0.813 | **+0.004** |
| MVP율 | 0.213 | ≈0 |
| 판수 | **0.070** | — |

사용자가 요구한 순서 — 승리의 질 > 승률 >>> KD > MVP — 가 **그대로 나온다.**
판수 상관 0.070 은 "많이 한다고 안 올라간다"는 뜻이다.

## B-2. 퍼포먼스 비중은 **±2%** 를 권고 (±5% 에서 하향)

| 비중 | 실력 상관 | **승리의 질 상관** | KD 상관 | 스나-서포트 편향 |
|---|---|---|---|---|
| ±0% | 0.908 | **0.993** | 0.761 | −14.4 |
| **±2%** | 0.908 | **0.979** | 0.765 | **−4.7** ← 편향 최소 |
| ±5% | 0.909 | 0.897 | 0.770 | +9.6 |
| ±10% | 0.909 | **0.634** | 0.780 | +33.1 |

**실력 재현도는 전 구간 동일한데 "승리의 질" 정렬만 무너진다.**
±10% 에서는 0.993 → 0.634 로 붕괴한다. 사용자가 1순위로 지목한 지표를 깎으면서
정확도는 하나도 못 산다. ±2% 는 포지션 편향도 가장 작다(|−4.7|).
