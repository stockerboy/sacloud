## 1. 스냅샷을 어떻게 만들었나

최종 시즌 결과를 1/3 · 2/3 으로 나누지 **않았다.** 그러면 그 시점의 신뢰도 ·
승률 자격선 · 활동 페널티가 전부 틀린 값이 된다.

day N 스냅샷 = **day N 까지의 경기만** 시간순으로 재생 + 감점 tick 도 day N 까지만.
즉 그날 실제로 리더보드를 열어 본 것과 같다.

검증: `snapshotAt(90)` 의 결과가 전체 시즌 replay 와 **모든 행에서 완전히 일치**한다.

측정 규모: 시나리오 36 run × 스냅샷 7일(7/14/30/45/60/75/90).
