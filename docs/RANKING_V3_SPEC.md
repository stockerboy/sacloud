> **아직 운영에 안 넣었다.** 이 문서는 설계와 근거만 담는다.
> 적용은 P0 파이프라인 24시간 무인검증을 통과한 뒤 사장님 결정으로 한다.

## 0. 이 공식이 답하려는 질문

사장님 말씀 (2026-09-08):

> «핵심은 “내가 어느 티어 클랜 소속인가”가 아니다.
>  **“내가 어느 티어 클랜들을 상대로 얼마나 많이 싸웠고, 거기서 얼마나 잘했는가”** 다»

> «승률도 중요하지만 **어느 클랜이랑 해서** 높은 승률인지가 중요한거임»

> «점수가 구린데도 성적이 조금 더 좋아서 낮은 클랜이 치고 올라오면
>  사람들은 안 믿는다. 부정확하다고 생각한다» → **정확도보다 신뢰가 먼저**

즉 **「누구를 상대로 얼마나 검증됐는가」** 를 재는 랭킹이다.
단순 승률 랭킹도, 소속 티어 랭킹도, K/D 랭킹도 아니다.

## 2. 클랜 점수

```
점수 = 티어 기준점 + (Elo − 3000) × √( 경기수 ÷ 50 )

  티어 기준점   1티어 3300 · 2티어 3150 · 3티어 3000 · 4티어 2850 · 5티어 2700
  Elo          K=50 · 억제 없음 · 배치고사 없음 · ★본클랜원 가중치 제거★
  모집단        Cloud 0 창 · canonical · 양쪽 LeagueClan 확정 · 승패 확정 · supersededAt null
               ★라인업이 없어도 클랜 승패·Elo 에는 포함한다★
```

### 왜 이렇게 정했나 — 전부 실측으로 고름

**① 라인업 없는 경기를 넣는 이유**

| 리그 | 창 안 경기 | 전적에 잡힘 | **빠짐** |
|---|---|---|---|
| IPL | 1,628 | 1,556 | 72 (4.4%) |
| SPL | 454 | 334 | **120 (26.4%)** |
| 10mountain | 367 | 361 | 6 (1.6%) |

`deluxe` 는 **62경기를 뛰고도 「0승 0패 · 배치중」** 으로 랭킹에서 사라져 있었다.
62경기 전부 라인업이 없었기 때문이다.

**② 본클랜원 가중치를 빼는 이유**

IPL 클랜의 `compositionMembers` 가 **전원 0** 이었다.
가중치 곡선이 `[1→0.3 … 5→1.0]` 이라 0 은 첫 칸으로 떨어져
**모든 IPL 클랜의 증감이 30% 로 깎이고 있었다.** 래더 폭 202점의 진짜 원인이다.

사장님: «`compositionMembers=0` 은 「본클랜원 0명」이 아니라 사실상 **모름** 이다.
모르는 값을 이유로 30%로 줄이지 않는다» → 제거. 로스터가 믿을 만해지면 별도 설계.

**③ 티어 기준점 간격 150 을 고른 근거**

| 간격 | 사장님 순서와 | 티어 넘은 쌍 | **말이 안 되는 역전** |
|---|---|---|---|
| 0 | 0.610 | 186쌍 | 22쌍 |
| 60 | 0.913 | 52쌍 | 3쌍 |
| 100 | 0.952 | 28쌍 | 0쌍 |
| **150** | **0.971** | **8쌍** | **0쌍** |
| 200 | 0.976 | 1쌍 | 0쌍 |
| 300 | 0.977 | 0쌍 | 0쌍 |

「말이 안 되는 역전」 = 판수도 적고 승률도 낮은 클랜이 위로 오는 것.
150 에서 0쌍이 된다. 200·300 은 더 깨끗하지만 **랭킹이 티어를 그대로 베낀 것**이 된다.

**④ 티어를 넘은 8쌍은 전부 근거가 있다**

```
10위 Atraxia   3T 108판 60%  >  11위 idylic    2T   5판 40%
10위 Atraxia   3T 108판 60%  >  12위 evermore  2T 104판 45%
17위 adererror 4T  45판 58%  >  18위 pleniIune 3T 155판 52%
27위 vAN`kA    5T  24판 71%  >  31위 Asterisk  4T 155판 45%
```

⚠ `publicity`(5T 45%) > `Asterisk`(4T 45%) 한 쌍만 승률이 같아 애매하다.
간격을 200 으로 올리면 이 쌍이 사라진다. **[사장님 결정 대기]**

## 3. 개인 점수

### 후보 세 개를 전체 replay 로 비교했다 (IPL 1,448명)

| 후보 | 내용 | 사장님 1~30위 재현도 |
|---|---|---|
| A | 높은 티어끼리 보너스 (내 티어 + 상대 티어)÷2 | 0.811 |
| B | **상대 티어만** 가중 (내 소속을 안 봄) | 0.815 |
| C | **티어별 경기량 + 승률을 직접 점수화** | 0.886 |
| **D** | **C 를 언덕오르기로 더 맞춘 것** | **0.9742** |

**후보 D 가 최종안이다.**

```
점수 = Σ(티어 t) V[t] × ( 13.6 × 경기수^0.67 + 6.4 × (승수 − 0.5 × 경기수) )
       − 18.6 × √(총 경기수)

  V[1] = 1.000   V[2] = 0.991   V[3] = 0.367   V[4] = 0.362   V[5] = 0.332
```

파라미터는 **임의로 정하지 않았다.** 티어가치 5개 + 계수 5개를 자유롭게 두고
언덕오르기 40회 재시작 × 1,500번을 돌려 **사장님 1~30위를 가장 잘 재현하는 조합**을 찾았다.

### 이 공식이 말하는 것 — 사장님 감각의 정체

1. **1티어와 2티어가 사실상 같은 값** (1.000 / 0.991)
2. **3티어부터 확 떨어지고 3·4·5는 서로 거의 구분 안 함** (0.367 / 0.362 / 0.332)
   → 랭킹은 **「1·2티어를 상대했느냐 아니냐」** 하나로 갈린다
3. **√총경기수 계수가 −18.6 (음수)** → 판을 많이 뛰는 것 자체는 이득이 아니다
4. 성적항이 `승수 − 0.5×경기수` → **1승 0패는 +0.5 뿐** (표본 문제 자동 해결)

### 과적합 검산

30명에 계수 10개라 과적합 위험이 있다. 그래서 **31~45위로 따로 검산**했다 — **0.896**.
30명에만 억지로 맞춘 것이면 이 값이 확 떨어진다. 떨어지지 않았다.

### 사장님 전제가 데이터로 확인됨 — 서백곰`rB

```
소속 reBelIion(4티어) · 56판 71%
  vs 1티어   ★0판★        ← 한 판도 안 만났다
  vs 2티어   2판 ★0%★      ← 두 판 다 졌다
  vs 3티어   2판 50%
  vs 4티어   28판 71%
  vs 5티어   24판 79%
  → 56판 중 ★52판(93%)이 4·5티어★

순위   지금 ★1위★ → A 28위 → B 34위 → C 66위 → D 31위
```

사장님: «4티어 중심 71% 라면 전체 최상위권까지 가면 안 된다» → **맞았다.**

## 5. 미참여 감점 — 건드리지 않는다

**규칙 변경 없음.** 이 점수 위에 **별도 층**으로 그대로 얹는다.

실측 (2026-09-08) — IPL 시즌0 참가 1,448명 · 유예 7일 · 30일이면 3000점까지
```
지금 감점 대상 0명   ← 창이 열린 지 5.3일뿐이라 당연
09-10 까지 안 뛰면      6명
09-12 까지 안 뛰면    309명 (21%)
09-15 까지 안 뛰면  1,448명 (100%)
```
**아직 한 번도 작동한 적이 없다.** 09-10 부터 갈라지므로 그때 다시 재야 한다.

## 7. 근거 파일
