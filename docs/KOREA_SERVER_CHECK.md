# 한국 서버에서 병영수첩이 열리는가 — **명령 세 줄**

> 작성 2026-09-03 · O-051 · **계정이 생기는 순간 30초 안에 답이 나오게** 미리 적어 둔다.

---

## 0. 왜 이것만 남았나

```
집 IP (KR · SK브로드밴드 가정망)   ★200★   ← 오늘 120건 요청 · 403 0건
GitHub 실행기                     ★403★   ← run 7 주석이 답했다 (D-269)
```

**「클라이언트가 갈린다」(D-268) 위에 「IP 도 갈린다」가 하나 더 있었다** (D-269).

⚠ 그런데 **그 실행기가 어느 나라인지 안 봤다.** GitHub 실행기는 보통 외국이다 —
**넥슨이 막는 게 「데이터센터」가 아니라 「해외」일 수 있다.**
**그러면 한국에 있는 서버는 통과한다. 그건 아무도 안 재봤다.**

`barracks-collect.yml` 이 이제 실행기의 **나라를 주석으로 남긴다.** 다음 판이 그 절반을 답한다.
**나머지 절반(한국 데이터센터)은 그 위에서 돌려 봐야만 안다.**

---

## 1. 사장님이 하실 것 — 계정 만들기

**계정 생성은 우리가 하지 않는다.** 사장님 명의이고, 카드 인증이 있다.

```
오라클 클라우드 Always Free   ★평생 무료★ (12개월 아니다)
  ⚠ ★홈 리전을 「서울」로 고르셔야 한다★ — Always Free 는 홈 리전에서만 만들어진다
    (춘천을 고르시면 Ampere A1 이 안 되고 ★AMD Micro★ 만 된다. 그래도 이 시험엔 충분하다)
```

출처: [Oracle Always Free Resources](https://docs.oracle.com/en-us/iaas/Content/FreeTier/freetier_topic-Always_Free_Resources.htm)

## 2. 우리가 할 것 — **이 세 줄**

서버에 붙어서 그대로 붙여 넣는다. **넥슨에 요청 3건.** 다른 건 아무것도 안 한다.

```sh
# ① 이 서버가 어느 나라인지 (넥슨에 안 보낸다)
curl -sS "http://ip-api.com/json/?fields=countryCode,isp,as"

# ② 첫 페이지
curl -sS -o /dev/null -w 'home %{http_code}\n' --max-time 30 https://barracks.sa.nexon.com/

# ③ 진짜 자료 — ★본문이 없으면 405 다★ (D-268)
curl -sS -o /dev/null -w 'battlelog %{http_code} %{size_download}bytes\n' --max-time 30 \
  -X POST -H 'Content-Type: application/json' --data '{}' \
  https://barracks.sa.nexon.com/api/BattleLog/GetBattleLogClan/260805205259124001/170430000194
```

### 읽는 법

```
② ③ 이 ★200★        → ★됐다.★ 그 서버에서 수집을 돌린다. ★서플라이 줄이 끊긴다★
② ③ 이 ★403★        → ★한국이어도 데이터센터가 막힌다★ 는 뜻이다.
                       ★그러면 남는 건 가정용 회선 하나뿐이다★
③ 만 ★405★          → ★본문을 안 보낸 것이다.★ 막힌 게 아니다 (D-268)
```

⚠ **403 이면 거기서 멈춘다.** 다시 시도하지 않고 우회를 만들지 않는다
(`CLAUDE.md` 3-A 5번 · D-266 «차단은 우회 대상이 아니라 멈춤 신호다»).

## 3. 200 이 나오면 그 다음

```
1 그 서버에 저장소를 내려놓고 `pnpm install`
2 `DATABASE_URL` 을 환경변수로 (★값을 로그·커밋에 남기지 않는다★)
3 nexon barracks-collect --clans 10 --limit 120 --confirm --health https://3rdcloud.my/api/health
4 15분마다 — ★cron 이 아니라★ 잡이 15분을 채우고 다음을 부르는 방식
  (`barracks-collect.yml` 이 그 모양이다. 그걸 그대로 옮긴다)
```

⚠ **유휴 회수 조건이 있다** — 7일간 **CPU 95백분위 <20% AND 네트워크 <20% AND 메모리 <20%**
**셋 다** 미달이면 인스턴스를 회수한다. 15분마다 30초 도는 잡은 **위험이 있다.**
알고 있어야 하고, 회수되면 다시 만들면 된다 (무료다).
