## Phase 7 — DB + 실제 API (2026-08-21)

### 한 일

**기반**
- `packages/db` 신설. Prisma 스키마를 계약(Zod)을 채울 수 있는 형태로 설계하고,
  `CLAUDE.md` 3-A(마이그레이션 절대 규칙)를 **스키마 수준에서 강제**했다.
  `RawImport`(원본 응답 보존) · `SourceMapping`(원본 ID 보존) · `ImportJob`/`ImportFailure`
  (중단 후 재개, 실패 기록) · `MigrationCheck`(숫자 대조) · 경기 시점 division 스냅샷 ·
  래더 재현 정보 · 무기별 분리 · 시즌 스냅샷 · `RatingConfig`.
- 로컬 PostgreSQL을 `embedded-postgres`로 띄웠다 (Docker·PostgreSQL 미설치 환경).
  한국어 Windows에서 `initdb`가 두 번 막혔고 둘 다 원인을 찾아 우회했다 (D-022).
- Mock과 **같은 결정적 픽스처**를 DB에 적재하는 시드 + 자가 점검(`pnpm db:check`).

**API**
- 계약 엔드포인트 전량을 Prisma 기반 Route Handler로 구현 (57개 라우트).
- 쓰기가 **실제로 저장된다**: 글·댓글·추천·설정 변경. 서버 측 새니타이즈 · rate limit ·
  권한 검사 · 비로그인 글 비밀번호 해시.
- 인증은 `jose`(JWT) + `bcryptjs`로 직접 구현. httpOnly 쿠키 + 리프레시 토큰 rotation.
  계획 문서의 Auth.js와 다른 선택이라 사유를 남겼다 (D-025) — **사용자 확인 필요**.

### 검증

- **`pnpm compare` 신설** — Mock과 실제 API의 응답을 **값까지** 재귀 비교. **25/25 일치.**
- 계약 준수 테스트 9건 (실제 응답을 계약 Zod로 파싱).
- typecheck / lint / test(157건) / build 전부 통과.
- mock 모드로 되돌려 주요 화면 회귀 확인.

### 발견하고 고친 것

- **랭킹·기록실이 화면에서 404** — 계약은 `:leagueId`인데 화면은 슬러그를 넘긴다 (D-028).
  curl과 계약 테스트로는 못 잡고 **실제 화면을 열어야** 드러난 종류였다.
- **Phase 0 픽스처 3건의 시각이 id 순서와 어긋나 있었다** (D-029).
  게시글·댓글·리그 참여 시각. 목록이 최신순인데 시각 열이 뒤죽박죽으로 보이던 상태였고,
  DB(시각 정렬)와 순서도 달라졌다. 회귀 테스트 4건을 추가했다.
- Next 서버 번들에서 `Prisma.sql`이 동작하지 않는 문제 (D-027).

### 남은 것 / 확인 필요

- **Chrome 창이 최소화돼 있어 확장이 응답하지 않는다.** 스크린샷과 나머지 화면 검수를 못 했다.
  창을 복구한 뒤 다시 확인해야 한다.
- **서든어택 계정 연동이 소유권을 증명하지 않는다.** 운영 노출 전 반드시 해결.
- 캡차 · 이메일 발송 · 이미지 업로드(오브젝트 스토리지) · 리치텍스트 에디터는 아직 없다.
- Auth.js 미사용 결정(D-025)에 대한 사용자 확인.

### Phase 7 화면 검수 (2026-08-21)

프로덕션 빌드(`pnpm build` + `start`)로 검수했다. 개발 서버는 라우트마다 첫 요청에서
컴파일이 일어나 화면 하나에 수십 초가 걸리고 렌더러가 멈춰, 앱 문제와 구분이 안 됐다 (D-032).

**확인한 화면** — 홈 / 로그인 / 회원가입 / 마이페이지(내 정보·정보 수정·비밀번호 변경·계정 연동) /
게시판 목록 / 글 상세 / 글쓰기 / 댓글 / 추천 / 클랜랭킹(1·2부) / 개인랭킹 / 리그홈 /
클랜 기록실 + 매치 상세 펼침 / 개인 기록실 / 지난시즌 / 클랜 프로필 / 클랜원 / 플레이어 프로필

**실제로 조작해서 확인한 것** — 로그인 → 복귀, 로그아웃, 회원가입(실제 계정 생성),
닉네임 변경 저장, 글쓰기(실제 저장), 댓글 작성, 추천, 매치 상세 아코디언.

**발견하고 고친 결함 3건**
1. 로그인 성공했는데 화면이 로그인 페이지에 남음 (D-031)
2. 1번을 고치다 만든 회귀 — 보호막이 화면을 다시 마운트해 "저장했습니다"가 사라짐 (D-031)
3. **로그인 1시간 뒤 말없이 로그아웃** — 리프레시 토큰을 쓰지 않고 있었다 (D-030)

**끝내지 못한 것** — 리그 목록 표 / 리그 관리(소유자 화면) / 리그 만들기 / 통합검색 UI /
404 화면 / 작은 화면 레이아웃의 **스크린샷 확인**. Chrome 창이 포그라운드가 아니어서
탭이 `hidden`으로 throttle됐다(D-019). 권한과 API는 서버 수준에서 확인했다.
