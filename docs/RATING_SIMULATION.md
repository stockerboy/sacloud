## 1. 가정과 공식

### 개인

```
baseline           3000
K                  60
퍼포먼스 비중       ±10%
신뢰도 적용        display

expected  = 1 / (1 + 10^((Ro - R)/400))
baseDelta = K × (actual - expected)
delta     = baseDelta + |baseDelta| × 퍼포먼스비중 × perf(-1~+1)
display   = 3000 + (internal - 3000) × confidence      (display 모드)
```

퍼포먼스를 **곱하지 않고 더한다.** 곱하면 패배했을 때 잘한 사람이 더 깎이는 뒤집힌 결과가 나온다.
그래서 승리는 더 받고, 패배는 덜 잃는 방향으로만 움직인다.

신뢰도 구간 — 1~30 40% · 31~60 55% · 61~90 70% · 91~120 85% · 121~149 95% · 150+ 100%.
150판 이후로는 더 해도 올라가지 않는다 (판수 박치기 차단 지점).

### 클랜

