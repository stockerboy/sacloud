# SUPPLY_MEASURED.md — 서플라이를 **재서** 적은 값

> 2026-09-22 밤. 눈으로 본 것이 아니라 **CDP 로 잰 것**이다.
> 재는 법: `node scratchpad/measure.mjs <url> <가로> <세로> scratchpad/spec.js`
> (`spec.js` = 카드처럼 생긴 것 전부 · `shell.js` = 위쪽 껍데기)
>
> ⚠ **원본의 코드·이미지·클랜마크·약관 문구는 베끼지 않는다** (`CLAUDE.md` 2-4).
> 여기 적는 것은 **관찰한 치수와 색**이다. 마크업은 우리가 새로 쓴다.

## 0. 왜 이 파일이 있나

사장님: 「껍데기는 서플라이랑 똑같은데 몇 가지 기능이 추가된 사이트 /
모든 카드 디자인·색 전부 서플라이랑 똑같이 / 다른 사람이 봤을 때
‘어 이런 기능이 추가됐네?’ 느낌이 날 정도로」 (2026-09-22 밤)

그동안 「비슷하게」를 **눈대중**으로 맞추다 다섯 번 어긋났다 (`STATE.md` 0-홈).
그래서 **숫자를 한 곳에 모은다.** 화면을 고칠 때 여기 값을 본다.
