## 2. 색상 규칙 (절대)

| 함수 | 대상 | 규칙 |
|---|---|---|
| `rankColor(rank)` | 등수 · 닉네임 · 특성 등수 | 1~3 빨강 `#ff4d4d` / 4~20 노랑 `#ffd83d` / 21~40 파랑 `#5b9dff` / 41~100 초록 `#22c55e` / 101~ 하양 |
| `statColor(v)` | 0~100 스케일 수치 (승률·킬뎃) | ~39.9 빨강 / 40~49.9 하양 / 50~54.9 초록 / 55~59.9 갈색 / 60~64.9 파랑 / 65~100 노랑 |

래더 점수는 규칙 밖 — 흰색. K/D/A 는 **킬·어시 흰색, 데스 빨강**.

**ASTRA 는 무조건 영롱하게** (`ASTRA_STYLE`: 홀로그램 그라데이션 + 글로우 + 5.5s 시머).
**CHALLENGER 는 그보다 약하게** (`CHAL_STYLE`: 단색 브론즈 `#a98a64`).

## 3. 클랜 테마

선수 카드 KPI 줄 배경은 **소속 클랜의 클랜마크에서 뽑은 색**입니다.

```ts
const IGLOO: ClanTheme = { light:'#e6f7f7', main:'#81d3ef', deep:'#3cb0d2', edge:'#a8e8ff', ink:'#bfe6ff' };
```

- `edge` → 카드 상단 2px 라인 · 엠블럼 링
- `light`/`deep` → `<ClanBackdrop>` 의 위/아래 그라데이션
- `ink` → 닉네임·클랜명 텍스트
- 마크 이미지는 **원 크롭된 파일**(`igloo-fit.png`)을 쓰고 `background-size:100% 100%` + `border-radius:50%` 로 표시하세요. `cover` 를 쓰면 마크 테두리가 잘립니다.

다른 클랜이면 `IGLOO` 상수와 `MARK` 경로만 교체하면 됩니다.

## 4. 구간별 전적 — 데이터는 계산해서 쓴다

```ts
const REGION_RAW = [
  [33, 18, 132, 103, 312, 273],  // ASTRA        [승, 패, 스나킬, 스나데스, 라플킬, 라플데스]
  [ 6,  4,  23,  24,  57,  61],  // CHALLENGER 1
  null,                          // CHALLENGER 2 (기록 없음)
];
```

- 판수 = 승+패, 승률 = 승/판수, 킬뎃 = 킬/(킬+데스), 판킬 = 킬/판수 — **전부 계산**. 퍼센트 하드코딩 금지.
- 합계가 상단 KPI 와 맞아야 합니다: 39승 22패(61전), 524킬 461데스 = 53.2%, 8.6킬/판.
- **10판 미만**이면 승률·킬뎃을 숨기고 "10판 이상 기록이 쌓이면…" 안내만 표시.
- ASTRA 만 킬뎃을 스나/라플 페어로, CHALLENGER 구간은 "통합 승률 / 통합 킬뎃" 단일 표기.
- 구간 선택 칩은 **헤더 아래 별도 줄**에 둡니다 (헤더에 넣으면 절반 폭 카드에서 넘칩니다).

## 5. STRENGTH POINT (6각 그래프)

축 순서는 시계방향, 12시부터: **세이브 → 샷싸움 → 캐리력 → 선짤 → 연속킬 → 소수싸움**

| 축 | 의미 | 10위 이내 배지 |
|---|---|---|
| 세이브 | 열세 상황을 뒤집어 살린 라운드 수 | 세이브 머신 |
| 샷싸움 | 1:1 교전 승률 | 샷터 |
| 캐리력 | 팀 승리 기여 비중 | 캐리 머신 |
| 선짤 | 라운드 첫 킬 횟수 | First Blood |
| 연속킬 | 한 라운드 2킬 이상 횟수 | 멀티킬러 |
| 소수싸움 | 수적 열세 교전 승률 | 말맞추기 |

- `value`(0~100)는 **그래프 면적만** 결정, 화면에 보이는 건 `rank`(리그 등수).
- **배지 규칙**: 등수가 **10위 이내**일 때만 그래프 아래 "특성" 줄에 배지를 단다. 11위부터는 배지 없음.
- 배지 색은 골드 `#ffd83d` 고정 — 등수 색상 규칙과 별개인 연출.
- ⚠️ 육각형 SVG 는 **viewBox(300×262)와 표시 크기(300px)를 1:1** 로 유지하세요. 축소하면 내부 텍스트도 같이 줄어 8px 이하가 됩니다. 그래서 `flex:0 0 300px` 입니다.

## 6. 추이 차트

- 승률(파랑) + 킬뎃(빨강), 각각 3겹(헤일로 → 중간 → 코어)으로 그려 네온 느낌을 냅니다.
- 두 선이 **서로 교차·역전**하도록 키포인트를 설계했고, `buildSeries()` 가 "경기 없는 주"를 평평한 구간으로 섞습니다(62% 확률).
- x축은 주 단위 `9/3 → 10/1`, 우측 끝은 `today` 세로선.
- 선 끝 마커: 승률 = **클랜마크 원**, 킬뎃 = **K/D 원**. 중심을 선 끝(`KX1`)에 정확히 맞춥니다.
- 라벨은 `퍼센트 → 전적` 순서 (`63.9% 39승 22패`, `53.2% 524킬 461데스`).
- ⚠️ **플롯 우측 끝을 500 으로 당겨** 라벨 영역 140 units 를 확보한 상태입니다. `KX1` 을 다시 556 으로 올리면 전적 라벨이 viewBox 밖으로 잘립니다.
- 캡션: "그래프는 매일 오전 3시에 찍힙니다 · 2판 미만인 날은 찍히지 않습니다"
- 기간 필터는 **DAY / 누적** 두 개.

## 7. 최근 경기 · 스코어보드

**MVP 는 단일 원천**입니다. 경기 데이터의 `mvpName` 하나가 진실이고,
- 헤더 배지는 그게 **본인일 때만** 표시
- 스코어보드 배지는 **그 선수 행에만** 표시
- 패배 경기는 상대팀 MVP (본인 팀에는 배지 없음)

**수치는 라운드 스코어와 정합해야 합니다.**
```
팀 총킬 T = 승리 라운드 × 4
이긴 팀 총킬 = 진 팀 총데스   (교차 검증 성립)
```
`spread()` 가 총합을 5명에게 내림차순 배분하고, `buildTeam()` 이 킬/데스/어시를 만듭니다.
어시스트는 선수별 기본값 ± 경기별 변동이며 **0이면 "-"** 로 표시합니다.

행 연출:
- 본인 행: 시안 하이라이트 + 좌측 3px 엣지 + `ME` 워터마크(오른쪽 66%)
- 스나이퍼: `SNIPER` 워터마크(왼쪽 34%) — 두 워터마크는 겹치지 않는 고정 위치
- 팀 표기는 **2줄**(1줄 igloo VS 상대 / 2줄 ASTRA) — 한 줄에 넣으면 절반 폭에서 클랜명이 짜부라집니다

## 9. 레이아웃 함정 (실제로 깨졌던 것들)

1. **IPL 로고를 `position:absolute` 로 두지 마세요.** 폭을 차지하지 않아 좌우 텍스트와 겹칩니다. 띠는 `grid: minmax(0,1fr) auto minmax(0,1fr)` 3분할입니다.
2. 카드에 `overflow:hidden`(라운딩용)이 걸려 있으니 **그리드 트랙 합이 컨테이너를 넘으면 잘립니다.** 축소가 필요한 트랙은 `minmax(0,…)` + 자식에 `min-width:0`.
3. 절반 폭 카드에서 한 줄에 여러 수치를 넣을 때는 필요폭을 먼저 계산하세요. 킬/데스는 `132/103` 축약 표기를 씁니다.
4. 좌우 카드 높이는 `align-items:stretch` + 좌측 하단 블록에 `flex:1; justify-content:flex-end` 로 맞춥니다.
5. SVG `<text>` 의 **내용**은 데이터 바인딩보다 리터럴이 안전합니다(축 라벨을 리터럴 좌표로 둔 이유).
