# vps-probe — 국내 서버 한 대를 잠깐 빌려 병영수첩이 열리는지 본다

## 서버 터미널에 붙여 넣을 한 줄 (이것만 하면 된다)

```
curl -fsSL https://raw.githubusercontent.com/stockerboy/sacloud/main/scripts/vps-probe/setup.sh | bash
```

root 로 붙은 새 Ubuntu 24.04 서버의 터미널에 위 한 줄을 넣고 Enter. **5~8분** 뒤 화면에 이런 상자가 뜬다.
그 상자를 사진으로 찍어(또는 복사해서) 총괄에게 보내면 끝이다.

```
==================================================================
==  병영수첩 탐침 결과  (공인 IP 1.2.3.4)
==================================================================
==  puppeteer : home=200 · clan-match-list=200 · battle-log=200   webdriver=true
==  맨 크롬   : home=200 · clan-match-list=200 · battle-log=200   webdriver=true
==================================================================
```

`200` 이면 열린 것, `403` 이면 막힌 것이다. 전체 결과는 서버의 `/root/probe-result.json` 에도 남는다.
서버는 시험이 끝나면 **콘솔에서 직접 지운다** (안 지우면 요금이 계속 나간다).

---

## 왜 하는가

병영수첩은 서버(Node)에서 부르면 403, 진짜 크롬에서만 200 이다. GitHub 무료 실행기(Azure IP)에서는
진짜 크롬도 403 이었다. 그런데 **사장님 PC(집 IP)에서는 같은 크롬·같은 방식으로 3건 전부 200** 이었다
(2026-09-02 실측 · 아래 「알아낸 것」). 그러니 남은 질문은 하나다 — **국내 데이터센터 IP 면 열리는가.**
열리면 그 서버에 크롬을 상주시켜 IPL 기록을 자동으로 받는다. 안 열리면 사장님 PC 밖에 안 남는다.

## 사장님이 할 일 — 1순위 iwinv (국내 · 저렴)

1. https://www.iwinv.kr 가입 → 결제수단 등록. 관리콘솔은 https://console.iwinv.kr
2. 왼쪽 메뉴 **[컴퓨트] → [가상서버] → [생성하기]**
3. 고를 것 — **ZONE: 서울(어느 존이든) · 하드웨어: 1vCPU / 2GB 급 중 가장 싼 것 · 운영체제: Ubuntu 24.04 LTS (64bit)**
   서버 이름은 `barracks-probe`. SSH Key 설정은 **건너뛴다**(비밀번호로 쓴다). 보안설정·네트워크는 기본값
4. [선택 완료] → 만들어지면 **IP · 계정 · 비밀번호가 가입한 이메일로 온다.** 그 셋을 총괄에게 보낸다
   (iwinv 는 만들자마자 **하루치**가 책정된다 — 최저 사양 기준 월 5,600원이니 하루 약 200원)
5. 콘솔의 그 서버 화면에서 **[콘솔 접속]**(웹 터미널)을 열어 `root` / 이메일의 비밀번호로 로그인 → 맨 위 한 줄을 붙여 넣는다.
   웹 터미널에 붙여넣기가 안 되면 PowerShell 에서 `ssh root@<IP>` 로 붙어도 된다. 끝나면 서버를 **삭제**한다

## 2순위 — 네이버클라우드 (NCP)

1. https://www.ncloud.com 가입 → 결제수단 등록 → 콘솔 https://console.ncloud.com
2. **Services → Compute → Server → [서버 생성]** (VPC 환경). VPC 와 **Public Subnet** 이 없으면 먼저 하나씩 만든다 (기본값 그대로)
3. 고를 것 — **리전: 한국(KR) · 서버 이미지: Ubuntu (24.04 가 없으면 22.04 · 아래 주의) · 서버 타입: Standard 중 가장 작은 것(1~2vCPU) · 요금제: 시간 요금제**
   인증키는 **[새로운 인증키 생성]** → `.pem` 파일을 PC 에 저장(비밀번호를 볼 때 필요하다). ACG 는 `Default-acg`
4. 만들어지면 서버 목록에서 **[서버 관리 및 설정 변경] → [관리자 비밀번호 확인]** 에 `.pem` 을 넣어 root 비밀번호를 본다.
   **공인 IP** 는 자동이 아니다 — 왼쪽 **Public IP → [공인 IP 신청]** 으로 하나 받아 이 서버에 붙인다. IP 와 비밀번호를 총괄에게
5. `Default-acg` 에 SSH(22) 허용이 있는지 확인한 뒤 PowerShell 에서 `ssh root@<IP>` → 맨 위 한 줄을 붙여 넣는다. 끝나면 서버·공인 IP 를 **반납**한다

> ⚠ NCP 에 Ubuntu 24.04 이미지가 있는지는 **확인 안 됐다** `[미확인]`. 22.04 여도 `setup.sh` 는 그대로 돈다 (크롬·Node 설치 방식이 같다).
> ⚠ 이 PC 는 소켓이 자주 끊긴다(EFAULT). `ssh` 가 끊기면 **업체의 웹 콘솔**로 하는 편이 낫다 — 그래서 한 줄 붙여넣기로 만들었다.

## 예상 비용 (대략)

| | 최저 사양 | 과금 단위 | 이 시험 비용 |
|---|---|---|---|
| iwinv | 1vCPU/1GB 월 5,600원 (부가세 별도) · 2GB 급은 월 1만원 안팎 | **1일** 단위로 책정 | 하루치 **200~400원** |
| NCP | Standard 최소 사양 | 시간 요금제 선택 가능 | 1시간 **수백 원** (정확한 단가는 콘솔 화면에 뜬다) |

서버를 지우지 않으면 월 5,600원~수만 원이 계속 나간다. **끝나면 반드시 삭제·반납.**

## 파일

| 파일 | 하는 일 |
|---|---|
| `setup.sh` | 서버에서 도는 것. 크롬(x86)·xvfb·Node 24 설치 → 탐침 두 방식 실행 → 결과를 화면에 크게 + `/root/probe-result.json`. 저장소를 clone 하지 않고 스크립트 두 개만 GitHub raw 로 받는다 — **main 에 올라가 있어야 한다** |
| `bare-chrome-probe.mjs` | 「맨 크롬」 탐침. puppeteer 없이 크롬을 띄우고 CDP 를 **파이프**로 붙인다 (포트 없음 · 자동화 플래그 없음) |
| `../barracks-probe.mjs` | puppeteer 탐침 (기존). 둘을 나란히 돌려 차이를 본다 |
| `run.mjs` | **옛 방식(보존).** Vultr API 로 서울 서버를 만들고→결과 받고→지운다. 사장님이 Vultr 계정을 못 만들어 쓰지 않는다. `VULTR_API_KEY` 환경변수가 있으면 지금도 된다. `--dry-run` 은 API 를 안 부른다 |

## 알아낸 것 (2026-09-02 실측)

- 크롬 152 는 `--enable-automation` 없이 `--remote-debugging-pipe` 만 켜도 `navigator.webdriver === true` 다.
  그러니 「맨 크롬」이 webdriver 표시를 없애 주지는 **않는다.**
- 그런데 **사장님 PC(집 IP)에서 그 상태(webdriver=true)로 3건 전부 200** 이었다 —
  첫 페이지 2,847B · 매치목록 24,166B(`rtnCode 20`) · 배틀로그 63,875B.
- 따라서 Azure 실행기의 403 은 webdriver 표시가 아니라 **IP 쪽**이다. 국내 데이터센터 IP 가 되는지는 이 시험이 답한다.

## 읽는 법

| puppeteer | 맨 크롬 | 뜻 |
|---|---|---|
| 200 | 200 | 국내 데이터센터 IP 는 통과 → 이 서버에 크롬을 상주시키면 된다 (다음 단계: 15분마다 수집) |
| 403 | 200 | puppeteer 가 붙이는 무언가가 걸린다 → 맨 크롬 방식으로 상주시킨다 |
| 403 | 403 | 국내 데이터센터 IP 도 막힌다 → 사장님 PC(집 IP)만 남는다 (`scripts/barracks-autocollect/`) |

`200` 은 「길이 열려 있다」까지다. 수집이 된다는 뜻은 그 다음 시험이다.

## 하지 않는 것

- 회피 플래그 · UA 위조 · 쿠키 조작 없음 (`CLAUDE.md` 3-A 5번). `--no-sandbox` 하나는 root 에서 크롬이 안 뜨는 사정이다
- 저장 안 함 · 우리 창구로 안 보냄(토큰을 서버에 두지 않으려고) · 방식당 요청 3건 · 2초 간격
- 사람이 콘솔에서 돌리면 어떤 포트도 열지 않는다. (옛 `run.mjs` 방식일 때만 결과를 8080 에 잠깐 내놓는다)
