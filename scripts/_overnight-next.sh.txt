이 파일은 **다음 재시작 때 `scripts/overnight-collect.sh` 에 넣을 조각**이다.
**지금 돌고 있는 스크립트를 고치면 안 된다** — `sh` 는 파일을 읽어 가며 실행해서
중간에 바뀌면 **엉뚱한 줄부터 이어 읽는다.** 그래서 따로 적어 둔다.

## 무엇을 고치나

지금은 기간을 주면 (`COLLECT_FROM=260301 COLLECT_TO=260701`) **그 기간이 끝나는 순간 스크립트가 종료**한다
(「남은 것 0 — 다 받았다」). 3~6월은 4,400건이라 **약 두 시간이면 끝나고, 그 뒤로는 아무것도 안 한다.**

**아침까지 남은 시간이 그냥 놀게 된다.**

## 어떻게

「남은 것 0」일 때 **끝내지 말고 기간을 풀고 이어서 돈다.** 한 번만 푼다.

```sh
  if [ "${left:-1}" = "0" ]; then
    if [ -n "$range_args" ]; then
      say "★그 기간은 다 받았다 — 기간을 풀고 이어서 받는다★ (지정했던 것: ${range_args})"
      range_args=""
      continue
    fi
    say "★남은 것이 없다 — 다 받았다★"
    break
  fi
```

## 왜 이렇게

- **`break` 대신 `continue`** — 다음 판으로 넘어간다. 판 수(`ROUNDS`)는 그대로 지킨다
- **한 번만 푼다** — 풀고 나면 `range_args` 가 비므로 다음에 0 이 되면 진짜로 끝난다
- **무엇을 풀었는지 로그에 남긴다** — 아침에 「왜 8월을 받고 있지?」 하지 않게
